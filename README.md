# Sanapala Ravi Kumar - Personal Portfolio

A modern, responsive personal developer portfolio website built from scratch with HTML5, CSS3, and JavaScript.

## 🚀 Live Demo & Netlify Deployment

This website is configured for free, high-performance hosting on **Netlify** with automatic continuous deployment from GitHub:

### Deploying to Netlify
1. Push this repository to GitHub:
   ```bash
   git push -u origin main
   ```
2. Go to [app.netlify.com](https://app.netlify.com/) and sign in with your GitHub account.
3. Click **Add new site** > **Import an existing project** > **GitHub**.
4. Select the **`portfolio`** repository and click **Deploy portfolio**.
5. Once deployed, customize your site name under **Site configuration** > **Change site name** to get a custom URL like:
   `https://sanapala-ravi.netlify.app`

## 🛠️ Tech Stack & Features
- **Frontend**: Semantic HTML5, CSS3 Custom Properties (Variables), Vanilla JavaScript
- **Design System**: Sleek Dark Mode aesthetic with modern typography and glowing accents
- **Responsiveness**: 100% mobile-friendly with an animated hamburger drawer menu
- **Interactivity**: Dynamic scrollspy active link indicator, smooth IntersectionObserver entrance animations, and one-click copy buttons with toast notifications
- **Resume Integration**: Integrated direct PDF view and download link
