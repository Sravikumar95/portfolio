# Sanapala Ravi Kumar - Personal Portfolio

Modern, responsive personal developer portfolio website built with HTML5, CSS3, and JavaScript.

## 🚀 Live Demo & Deployment
You can deploy this site for free on **GitHub Pages**, **Vercel**, or **Netlify**:

### Option 1: GitHub Pages (Recommended)
1. Create a new GitHub repository named `portfolio` (or `<username>.github.io`) on [github.com](https://github.com/new).
2. Push this project to your repository:
   ```bash
   git remote add origin https://github.com/Sravikumar95/portfolio.git
   git branch -M main
   git push -u origin main
   ```
3. Go to your repository on GitHub:
   - Navigate to **Settings** > **Pages**.
   - Under **Build and deployment** > **Source**, select **Deploy from a branch**.
   - Select `main` branch and `/ (root)` folder, then click **Save**.
4. In 1–2 minutes, your website will be live at:
   `https://Sravikumar95.github.io/portfolio` (or `https://Sravikumar95.github.io` if named `<username>.github.io`).

### Option 2: Vercel
1. Go to [vercel.com](https://vercel.com) and log in with GitHub.
2. Click **Add New Project**, import the `portfolio` repository, and click **Deploy**.
3. Instant custom domain: `https://<project-name>.vercel.app`.

## 🛠️ Tech Stack & Features
- **Frontend**: Semantic HTML5, CSS3 Custom Properties (Variables), Vanilla JavaScript
- **Design System**: Sleek Dark Mode aesthetic with blue/emerald accents
- **Responsiveness**: 100% mobile-friendly with hamburger drawer menu
- **Interactivity**: Dynamic scrollspy active link indicator, smooth IntersectionObserver entrance animations, and copy-to-clipboard buttons with toast alerts
- **Resume Integration**: Integrated direct PDF view and download link
